PARTIAL = supported only in part; GAP = evidenced conflict/unsupported;
OPEN = missing fact/evidence; BLOCKED = unresolved dependency/access;
REVIEW = explicit human decision needed; N/A only for a proven false
applicability condition. Every unresolved row needs an explanation and
review function. Unknown parent -> unresolved child, never N/A.
SEC-02 still applies because SSO exists but SCIM does not.
