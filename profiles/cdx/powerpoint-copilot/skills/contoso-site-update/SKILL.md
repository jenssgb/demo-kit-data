# Contoso site update

Use this skill when someone asks for a site update, a status deck or a weekly update for a Contoso location (for example Fargo, Redmond or Seattle).

## Structure

Always build exactly five slides in this order:

1. **Title** – "Site update <site name>" plus the date of the update.
2. **Key numbers** – at most three big numbers with a one-line label each (for example open actions, days to go-live, incidents).
3. **What changed** – the one change people must know about, as a short headline and two or three bullets.
4. **Risks and blockers** – a table with the columns Risk, Impact, Owner, Due.
5. **Next steps** – up to four actions, each with an owner and a date.

## Style

- Headlines are full sentences that state the message, for example "Dock 3 closes on April 27", not "Dock 3".
- No more than 25 words per slide outside tables.
- Use the Contoso colors: Navy #0B3D91 for headlines, Harbor Teal #00A3A1 for highlights, Signal Amber #FFB000 only for warnings.
- Use Segoe UI. No clip art, no stock photos of handshakes.
- Write in plain language. Avoid internal abbreviations unless they are explained once.

## Sources

- Only use facts from the referenced files, emails or meetings. If a number is missing, write "tbd" instead of guessing.
- Add the source of each key number in the speaker notes.
